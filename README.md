# Partner_New_Deal

Dette repoet inneholder Telenor B2B prosessmateriell, interaktive beslutningsportaler og styringsunderlag.

## Innhold:
- **GIA Free SIMs Beslutningsportal** (`GIA/beslutningsnotat_free_sims.html`):
  - Interaktiv beslutningsstøtte for forvaltning og AI-agentbasert kontroll av 135 281 Free SIMs.
  - Beslutningsnotat i Markdown (`GIA/Beslutningsnotat - Forvaltning og AI-stotte for Free SIMS.md`).
  - PowerPoint-presentasjon for ledelsen (`GIA/Beslutningsnotat - Forvaltning og AI-stotte for Free SIMS pr 18.09.26.pptx`).
- **Salgsprosessen i Salesforce Lightning** (`index.html`):
  - 6-stegs prosessflyt, sjekklister, B2B-avtaleklausuler, FPP/KPI-kalkulator.
- **Askeladden Båter Portalen** (`askeladden.html`): Modelloversikt, spesifikasjoner, sammenligningsverktøy, kjøpsråd, feilsøking og driftskalkulator.
- **Brus-avstemning** (`brus.html`)
